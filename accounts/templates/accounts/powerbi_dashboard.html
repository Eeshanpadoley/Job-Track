Connect Power BI Desktop

One-time setup, then refresh when your data changes
  1. Click Download Power BI data above.
  2. Open Power BI Desktop and choose Home → Get data → Text/CSV.
  3. Select jobtrack_powerbi_data.csv and click Load.
  4. Build visuals using Status, Company, Source, ApplicationMonth and RequiredSkills.
  5. When applications change, download the updated CSV and replace the source file at the same path, then click Refresh.

This export is limited to the signed-in user's records and intentionally excludes interview notes.

Starter DAX measures

After loading the CSV, rename its table to JobTrack in Power BI if needed.
Get latest data →
Total Applications = COUNTROWS(JobTrack)
Interviews = CALCULATE(COUNTROWS(JobTrack), JobTrack[Status] = "Interview")
Offers = CALCULATE(COUNTROWS(JobTrack), JobTrack[Status] = "Offer")
Rejections = CALCULATE(COUNTROWS(JobTrack), JobTrack[Status] = "Rejected")
Interview Rate = DIVIDE([Interviews], [Total Applications], 0)
Offer Rate = DIVIDE([Offers], [Total Applications], 0)

Format Interview Rate and Offer Rate as Percentage in Power BI. These measures use the exact status labels stored in your data.
